# IAMClient4D Crypto Test

Console program that checks the crypto provider selected at compile time (LockBox3, TMS or TaurusTLS) through the public API: factories, `TUniversalJWTSignatureVerifier`, storage crypto provider and `TIAM4DAESMemoryTokenStorageRawKey32`.

## What it checks

| Area | Checks |
|------|--------|
| JWS vectors | RFC 7515 A.2/A.3/A.4, RFC 7520 4.1/4.2/4.3 and OpenSSL signatures for all RS*/PS*/ES* (RSA 2048/3072/4096, P-256/384/521), RS256/PS256 signatures starting with a zero byte: valid, tampered signature, tampered input; unsupported algorithms rejected |
| Key confusion | RS256 as PS256, EC key with RS256, RSA key with ES256, wrong curve, relabeled `crv`, point not on the curve |
| Algorithm names | Case-sensitive: `rs256`, `Rs256`, `none`, `HS256`, ... rejected by the universal verifier, the RSA/RSA-PSS/ECDSA verifiers and `SupportsAlgorithm` |
| RSA keys | Through the verifier and the provider directly: `e` = 1, `e` = 2 (RS and PS), `e` >= `n`, `e` over 64 bits with `n` over 3072 bits, `n` over 16384 bits, `n` of 1024 and 2047 bits (RS and PS) rejected although the signature math holds; `e` = 3, 64-bit `e`, `e` = 65537 + phi(n) < `n` (2048 bits), `n` of 8192 and 9216 bits accepted (TMS: `n` over 8192 bits rejected, without raising) |
| RSA minimum size | `TIAM4DRSAPublicKey.MinModulusBits`: default 2048, values outside 1024..16384 rejected; 1024 and 2047-bit keys accepted with the minimum at their size, rejected one bit above; 2048-bit keys rejected with 3072 |
| RSA lengths | Signature with its leading zero byte stripped or an extra zero byte rejected (verifier and provider); JWK `n` with a leading zero byte accepted |
| ECDSA encoding | DER signature, 2 * size +- 1 bytes, `r`/`s` = 0, = `n`, + `n` (P-521) rejected; provider, over the message (TMS, TaurusTLS) and over the digest (TaurusTLS): `R`, `S`, `x`, `y` padded or stripped, `R` and `S` swapped, tampered message or digest, digest one byte longer/shorter rejected |
| Storage provider | Roundtrip, 0-33 byte plaintexts, fresh IV, empty AAD, wrong AAD, tampered ciphertext/tag, truncated frame, wrong key; AES-256-GCM vectors (Go `crypto/cipher`) for GCM providers; Windows: plaintext of a frame failing authentication not left in freed memory; LockBox3: IV seed not predictable from the previous frame |
| Token storage | Save/load/clear with the factory provider and with a custom provider; invalid arguments |
| Concurrency | Shared verifier (all providers) and storage provider (TaurusTLS, the only one documented as thread-safe) used from parallel tasks; TaurusTLS: `TIAM4DOpenSSL.EnsureLoaded` from parallel tasks |
| Key cache (TaurusTLS) | Capacity limits; same results for every vector without the cache, while filling it and from it; hits and misses; RS* not looked up; least recently used dropped first; capacity lowered; rejected keys not cached; `n` with a sign byte on the same entry; parallel verification with a key dropped at every lookup; process memory stable over 3000 evicted and 3000 cleared keys (OpenSSL memory is not in the leak report); timing with and without the cache (printed) |

## Run

From a command prompt (RAD Studio 13, Win64 by default):

```bat
tests\Crypto\run_tests.bat
tests\Crypto\run_tests.bat Win32
tests\Crypto\run_tests.bat Linux64
```

The script builds `IAM4DCryptoTest.dproj` once per provider (`/p:Provider=LockBox3|TMS|TaurusTLS`, separate DCU/EXE folders) and runs each executable. The TaurusTLS build runs once per folder in `OPENSSL_DIRS` (default: the folders among `C:\OpenSSL3-<platform>` and `C:\OpenSSL4-<platform>` that exist, run skipped when none does; a folder set explicitly must exist). Linux64 runs through WSL with the distribution OpenSSL.

Variables: `RSVARS` (another RAD Studio), `OPENSSL_DIRS`, `TAURUSTLS_SOURCE` (TaurusTLS `Source` folder when not under `src\Lib`, e.g. from a git worktree).

The executable can also be run directly; the optional argument is the OpenSSL folder (TaurusTLS builds only):

```bat
IAM4DCryptoTest.exe C:\OpenSSL4-Win64
```

Exit code: 0 all passed, 1 failures, 2 fatal error (e.g. OpenSSL not found). Memory leaks are reported on stderr at exit (Windows).

## Vectors

`CryptoTestVectorsU.pas` is generated by `gen_vectors.py` (Python 3 standard library): it downloads RFC 7515/7520, extracts keys and signatures, and signs fresh vectors with the OpenSSL CLI (new keys on every run; ECDSA signatures repeated until `R` or `S` starts with a zero byte). The RSA key vectors (`RSA_KEY_VECTORS`) and the RS256/PS256 signatures starting with a zero byte are signed by the script itself and are deterministic: RFC 7515 A.2 key and keys from a seeded generator.

```bat
python tests\Crypto\gen_vectors.py C:\OpenSSL3-Win64\bin\openssl.exe
```
